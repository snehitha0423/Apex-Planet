# 📊 ApexPlanet Data Analytics - Task 1

## 📌 Project Overview

This project is part of the **ApexPlanet Data Analytics Internship**.

The objective of Task 1 is to perform **Data Immersion & Wrangling** by exploring the dataset, assessing data quality, cleaning the data, and preparing an analysis-ready dataset.

## 🎯 Objectives

- Load and understand the dataset
- Explore dataset structure
- Perform data quality assessment
- Handle missing values
- Remove duplicate records
- Detect outliers
- Create a data dictionary
- Generate a cleaned dataset for further analysis


## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Excel (.xlsx)



## 📂 Dataset

**Dataset Name:**

`ApexPlanet_DataAnalytics_Dataset.xlsx`

The dataset contains customer purchase information including:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Age
- Gender
- City
- Product
- Category
- Quantity
- Unit Price
- Total Sales


## 📋 Tasks Performed

### ✅ Data Access & Familiarization

- Loaded Excel dataset
- Displayed first and last five records
- Explored dataset shape
- Viewed column names
- Generated dataset information
- Generated summary statistics
- Created a Data Dictionary



### ✅ Data Quality Assessment

- Checked missing values
- Checked duplicate rows
- Verified data types
- Detected outliers using the IQR method



### ✅ Data Cleaning & Transformation

- Filled missing **Age** values using category-wise median
- Filled missing **City** values using the most frequent city
- Removed duplicate records
- Validated cleaned data
- Exported the cleaned dataset
